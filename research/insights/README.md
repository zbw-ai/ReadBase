# Insights

`insights/` 存放个人技术判断。

这里不是论文总结，也不是资料摘抄，而是经过阅读、实验、生产经验或长期观察后形成的工程观点。

## 适合写进 Insights 的问题

- 为什么 Agentic RL 会催生新一代训练基础设施？
- 为什么 DeepSeek 的价值不只在模型，而在工程体系？
- 为什么未来 checkpoint 会从保存机制变成训练平台调度能力？
- 为什么某个技术方向值得投入，另一个方向只适合观察？
