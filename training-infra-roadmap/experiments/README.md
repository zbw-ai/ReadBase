# Experiments

`experiments/` 用来记录实践验证。

很多知识不是读懂的，而是实验懂的。这里记录 benchmark、复现、参数对比、失败案例和工程观察。

## 规则

- 实验可以很小，但必须有问题意识。
- 记录环境、配置、命令、结果和结论。
- 不追求一次成功，失败实验同样有价值。
- 如果实验改变了工程判断，要链接到 `insights/` 或 `topics/`。

## Template

```text
# Experiment Title

## Question

## Environment

## Setup

## Commands

## Results
```
