# Personal Reading Inbox

用于临时保存尚未开始、正在阅读或已经读完的论文、文档、博客和代码仓库，避免关闭链接后遗失。

## 使用方式

```text
归档阅读链接：https://example.com
```

未指定状态时默认为 `未开始`。也可以明确指定：

```text
归档阅读链接：https://example.com
状态：阅读中
```

更新进度：

```text
更新阅读状态：https://example.com → 已读完
```

## 归档规则

- 按链接发送时间归入 `YYYY/YYYY-MM.md`，不按材料发布时间归档。
- 阅读状态使用 `未开始`、`阅读中`、`已读完`。
- 每条只记录类型、原始链接、添加时间、阅读状态和一句话描述。
- 相同原始 URL 再次出现时，更新首次记录，不跨月份重复添加。
- 这里不做优先级、影响力或 Training Infra 相关性判断。
